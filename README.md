# Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase professional skills, services, projects, experience, and contact information.

## 🌐 Project Overview

This portfolio website provides a clean and modern interface for presenting a professional profile and work.

The website includes:

- Home / Hero Section
- About Section
- Skills
- Services
- Projects / Work
- Testimonials
- Contact Page
- Social Media Links
- Download Resume Button
- Responsive Navigation
- Scroll-to-Top Button
- Search Interaction
- Responsive Design

## ✨ Features

### 🏠 Home Page

The Home page introduces the portfolio owner with:

- Name
- Professional title
- Short introduction
- Profile image
- Social media links
- Download Resume button
- Decorative design elements

### 👤 About Section

The About section provides information about the portfolio owner, professional background, skills, and experience.

### 💻 Skills

The Skills section presents technical and professional skills using visual indicators.

### 🛠️ Services

The Services section displays the services offered, such as:

- Product Design
- UI/UX Design
- Web Design
- Research
- Wireframing

### 📂 Work / Projects

The Work section showcases selected projects in a modern visual layout.

### 💬 Testimonials

The website includes a testimonial slider that automatically changes between testimonials.

### 📞 Contact Page

The `contact.html` page provides visitors with a dedicated page for contacting the portfolio owner.

It includes:

- Contact information
- Contact details
- Contact form
- Social media information
- Navigation back to other website sections

## 🛠️ Technologies Used

The project is developed using:

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
